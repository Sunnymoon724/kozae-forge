# create-notion-page

콘텐츠 파일로 Notion 페이지 하나를 생성합니다.

## 입력값

| 입력값 | 필수 | 기본값 | 설명 |
|---|---:|---|---|
| `content-file` | 예 | - | 콘텐츠 파일 |
| `parent-page-id` | 예 | - | 상위 페이지 ID |
| `title` | 예 | - | 페이지 제목 |
| `notion-token` | 예 | - | Notion 통합 토큰 |

## 출력값

| 출력값 | 기본값 | 설명 |
|---|---|---|
| `page-id` | - | 생성된 페이지 ID |
